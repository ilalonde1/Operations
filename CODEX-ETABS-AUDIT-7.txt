WHAT THE TOOL IS SUPPOSED TO BE

  An engineer points it at any job's plan DXFs plus any ETABS file from that job, and gets back a
  model with the building's geometry entered, so the hours go into engineering rather than typing.
  Agnostic: nothing in it knows about a particular building or office. Honest: anything read and
  not modelled appears in the report. Learning: an engineer's answer becomes a rule for every job
  afterwards with no code change.

THE QUESTION THAT MATTERS MOST

  This tool has produced models for exactly two buildings, and both were used to tune it. It has
  never built a model for a building it was not developed against. Everything else is secondary to
  that, including every finding in the five previous audits.

  There is now most of a third case on disk. \\Kor-fs01 holds engineer-authored ETABS models for
  30783, 30864, 30694, 30859, 30891 and 30662. Tonight 110 structural plan views were exported
  from 30783's Revit model, but they carry the linked architectural model, so concrete walls land
  on A-WALL among partitions and no layer pattern separates them.

  Answer this concretely: what does it take to put ONE building through this tool that it was not
  built against, and what happens when you do? If the answer is that the drawings cannot be made
  usable, say so plainly and say why — that is a finding, not a failure.

RULES OF EVIDENCE

  1. Measure the artifact. The report, the workbook, the documents and the suite are outputs of
     the thing under audit.
  2. Read shipped PDFs as text, not the HTML behind them.
  3. Objects named "K" plus a letter and digits were written by this tool; some files in the job
     folders are its own output round-tripped through ETABS. Establish provenance.
  4. A check is proved by failing on the defect it exists for, not by passing.
  5. Two buildings are not evidence about a third.
  6. State the file and the numbers behind every finding. A defect read off code is not a finding
     until you say what it does to a model an engineer opens.
  7. Where you cannot determine something, say so and say what would settle it.
