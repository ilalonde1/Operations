## THE LICENSURE PICTURE — KOR is already in (the real CA-vs-BC difference)
**KOR already holds California licensure and is already the structural engineer of record on completed California buildings.** John Markulin is a California-licensed **Structural Engineer** (PE/SE in CA/WA/AZ/TX), and KOR has sealed CA work — Simone Little Italy (performance-based seismic design via alternate-means approval) among **151 California projects** in its ERP. So for KOR's core developer-residential / mixed-use lane, **KOR can pursue and stamp California work today** — this is *not* a 2027+ entry gate.

**The real constraint is licensing DEPTH, not entry.** There's no CA–Canada reciprocity (BPELSG confirmed), so each *additional* engineer KOR wants stamping CA work licenses individually: FE (or waiver — BS+17yr / MS+13yr / PhD+1yr) → NCEES PE-Civil → CA Seismic Principles + Surveying exams → Civil PE → NCEES PE-Structural → CA SE (~2–4 yr; FE waiver plausible for seniors). **To run volume across all four metros, license 1–2 more seniors in parallel.** Two genuine *gates* remain: (1) **DSA public schools / HCAI acute-care hospitals** require a CA SE *plus* a school/hospital track record KOR doesn't yet have — defer those; (2) deep multi-metro volume needs more licensed staff. Join **SEAOC** (SEAOSC for SD/LA, SEAONC for the Bay) — the networking front door.
