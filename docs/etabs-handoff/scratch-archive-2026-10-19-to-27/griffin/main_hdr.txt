# MODULE DOCSTRING

KorConcrete — local FastAPI backend.

Thin API over the validated csa19 engine. Local-first (SPEC 7): runs on the
engineer's machine, no data leaves it. Endpoints kept minimal for the current
milestone (engine-backed section render + section properties + edition toggle +
checks framework contract). Capacity/DCR + diagram endpoints come next.
