## Why these questions and not just "how much"

Published AZBEX pricing is tiered on **in-office employees in the state of Arizona**, excluding
field crews and anyone without a company email address:

| AZ in-office employees | AZBEX, 1 yr |
|---|---|
| **1–10** | **$575** |
| 11–29 | $995 |
| 30–59 | $1,450 |
| 60–149 | $2,100 |
| 150+ | $2,950 |

**KOR has no Arizona office**, so the lowest tier should apply — worth stating up front so the
quote comes back right the first time. DATABEX and NVBEX prices are not published at all.

⚠ **The thing to pin down before paying:** their own site says DATABEX is **Arizona only, with
Nevada "coming soon."** NVBEX appears to be a *magazine*, not a database. If so, the bundle buys
a searchable design-team database for Arizona and news coverage for Nevada — which is still worth
having, but it is not two databases. Question 2 below settles it.

## What a good answer looks like

- **Q3 is the one that decides it.** DATABEX advertises ~3,000 active Arizona projects at $5M+
  with owner, design firm and GC contacts. If Prime Design Firm is populated on most of them,
  it replaces the trade-listicle basis Arizona currently rests on and is worth the money several
  times over. If it is populated on a fifth, it is a lead list, not a design-team layer.
  ⚠ This is the same trap the public feeds set — a field that exists is not a field that is
  filled. Ask for the fill rate, not the field list.
- **Q4 decides whether it compounds.** Export means it can be joined to the permit and
  plan-review work already built. No export means manual lookup, one project at a time.
- If they will not answer Q3 with a number, **take the trial and measure it ourselves** on a
  sample of Phoenix and Scottsdale projects we already hold.
