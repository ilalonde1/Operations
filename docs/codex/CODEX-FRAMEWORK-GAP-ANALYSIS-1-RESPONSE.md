### Existing controls more concrete than the rubric's wording

These deserve preservation, with their stated limits:

- **Evidence identity and vacuous-test detection.** `IssueCheck` refuses tracked dirty code and zero matching tests; issue resolutions cite pass events, and SQL definitions freeze important evidence fields. That is more precise than simply “provide test results.” It still cannot prove the chosen check tests the issue. [Q/Records/IssueCheck.cs:15–27,65–93; Q/Records/RecordStore.cs:343–357; K/db/173_EvidenceIsFrozen.sql:159–187.]
- **Skipped is not passed.** `stage_gate` records timeout, error, skipped and downstream not_run distinctly, refuses an unwritable log before execution, and stops progression. It needs meaningful configured commands and mandatory invocation. [F/tools/stage_gate.py:22–44,184–213,243–304.]
- **Exact package/page coverage.** HandoffGate checks the hashes of shipped files, every page of supporting PDFs and producer/looker differences. That is stronger than a generic reviewer tick box, although asserted identity and honest visual review remain unproved and alternate delivery routes matter. [K/Kor.Operations.EngineeringTools.Core/Review/HandoffGate.cs:8–42,191–198.]
- **Positive controls for enforcement.** `Rules.KnownAnswerFailures` tests MustAllow as well as MustRefuse and derives quoted/echo/commit-message variants that must remain allowed. This concretely tests a common source of false blocks. The examples' semantic adequacy remains a separate question. [Q/Enforce/Rules.cs:97–122.]
- **Move detection earlier after an actual failure.** `gate_earliest` records late failures and refuses the next covered Revit entry until they are answered. This is more operational than a generic LEARN stage. A thin “no” explanation, unobserved fault or alternate verb remains outside its guarantee. [K/tools/gate_earliest.py:1–18,103–122; K/tools/virtual_drafter.py:775–777,798–800.]
- **Honest measurement limits.** Scorecard deliberately reports UNKNOWN where records cannot attribute cost/reruns, while GuardRefusal separates unjudged from wrong. That is preferable to manufacturing a precise agent performance score. Source freshness also distinguishes changed file/blob identities from current ones, without claiming semantic truth. [F/tools/scorecard.py:19–59; K/db/167_EveryGuardIsMeasured.sql:76–85; Q/Records/Freshness.cs:26–36.]
