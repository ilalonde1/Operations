# LMFM Professional Engineers Prequalification — KOR Structural Execution Plan

*BD action plan · KOR Structural · 24 Jun 2026 · INTERNAL · Source: FMP reply + Bonfire opportunity 101915 + LMFM RFPQ structure (verified)*

## The big change: it's OPEN NOW

FMP confirmed the **2026 RFPQ for Professional Engineers is "Open and Ongoing"** — we do **not** wait for a fall window. Submissions are evaluated **on a rolling basis** (whenever enough accumulate, they go to the evaluation committee). 

- **Apply link (Euna/Bonfire):** https://fraserhealth.bonfirehub.ca/opportunities/101915
- **Close date:** 30 Sept 2026 — but FMP warns this **can be pulled forward** when they prepare the next Annual Refresh. Document takers are notified of an early close, but **do not rely on it — submit early.**
- **This is the VCH list** (LMFM acts on behalf of FHA, PHC, PHSA & **VCH** — confirmed on the RFPQ masthead). One application; covers VCH.

## Three rules FMP stated explicitly

1. **One submission per discipline.** KOR applies for **Structural only → one submission.** (Any additional discipline = its own separate submission.)
2. **References must be discipline-specific.** Each submission is supported by project references **specific to that discipline** (Structural).
3. **Allocate fees on multi-discipline projects.** Where KOR was one of several engineering disciplines on a project, state **KOR's structural fee portion** (not the whole engineering fee) — that is what's evaluated, and it's what places the reference in a fee band.

## Phase 1 — Decide scope & references BEFORE assembling (Ian + a principal, ~1 hr)

- [ ] **Discipline:** Structural — one submission. Confirmed.
- [ ] **Which cells to claim** (the roster is Acute vs Non-Acute × fee band: `<$150K / $150K–1M / $1M–5M / >$5M`):
  - **Claim Non-Acute** across every band KOR can back with a genuine reference.
  - **Claim Acute** only at bands where KOR has a true post-disaster / high-importance (IE=1.5) reference. **Do not over-claim** — references that don't substantiate a cell get rated down. It's fine to enter Non-Acute first and add Acute at the next refresh once a healthcare credit exists.
- [ ] **Pick the reference projects** (KOR's strongest Structural work) and map each to: care-type (Acute/Non-Acute), KOR's structural fee → fee band, role (SEoR), value, client, completion, reference contact.

## Phase 2 — Assemble the submission package (expected LMFM components — confirm vs the downloaded forms)

> These are the standard LMFM RFPQ-for-engineers components. The downloaded package in Phase 0 is authoritative; treat this as the prep checklist.

- [ ] **Completed RFPQ response forms / appendices** (firm profile, signed submission form, addendum acknowledgement, declarations).
- [ ] **EGBC standing** — proof KOR is an EGBC-licensed firm / **EGBC Accredited Employer** (since Jul 2023), plus a list of KOR's **registered structural P.Eng. staff**. (EGBC licensure is the qualifying gate.)
- [ ] **Key-personnel resumes** — principals + structural P.Eng leads; foreground **seismic / high-importance / post-disaster** experience and BCBC-2024 fluency.
- [ ] **Structural project references** — discipline-specific; expect a fixed number (commonly 3–5). Per reference: project name, owner/client, location, KOR's role (SEoR), **construction value + KOR's allocated structural fee**, completion date, reference contact (name/email/phone), and the **care-type + fee band** it supports.
- [ ] **Insurance** — Professional Liability (E&O) + Commercial General Liability; Certificate of Insurance or confirmation KOR can carry the required limits.
- [ ] **WorkSafeBC** clearance letter + any OHS/safety program statement.
- [ ] **Business licence** / corporate registration.
- [ ] **Conflict-of-interest / declarations** as required by the package.
- [ ] **Rated questionnaire responses** (experience, capacity, QA/QMS, references) if the package includes a scored questionnaire.

## Phase 3 — Submit early (target: within ~2 weeks, well before 30 Sept)

- [ ] Upload each required file to its **correct Bonfire slot** (one Structural submission). Bonfire rejects a submission with empty mandatory slots.
- [ ] Check **file format / size limits** Bonfire enforces per slot.
- [ ] **Submit** and capture the Bonfire **confirmation** (screenshot + email). Keep it on file.
- [ ] Because evaluation is ongoing and the close can move up, **do not sit on a near-complete package** — submit as soon as Phase 2 is clean.

## Phase 4 — After submission

- [ ] Watch the Bonfire inbox + the registered email for **clarification requests** — respond fast (rolling evaluation rewards responsiveness).
- [ ] On qualification, KOR appears on the next refreshed **Pre-Qualified Professional Engineers** list at the cells awarded — then KOR is invited to LMFM/VCH tenders + proposal calls in those cells.
