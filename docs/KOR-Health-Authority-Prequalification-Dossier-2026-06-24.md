## 6. FMP correspondence (ingested)

**Sent** to FMP@fraserhealth.ca: inquiry confirming KOR (EGBC Accredited Employer) wants on the LMFM Pre-Qualified Professional Engineers list (Structural), asking timing, portal and submission requirements.

**Reply received** (verbatim, key content):

> The current 2026 RFPQ Open and Ongoing opportunities are posted on BC Bid, with submissions completed through the Euna/Bonfire platform.
> Direct link for Professional Engineers: https://fraserhealth.bonfirehub.ca/opportunities/101915
> Please note that if your firm is applying for multiple disciplines under Professional Engineers, a separate submission is required for each discipline, supported by project references specific to that discipline. For projects that include more than one discipline, the engineering fees must be allocated accordingly for evaluation purposes.
> Euna/Bonfire requires a closing date for all postings; therefore, the current close date is listed as September 30, 2026. This date will remain unless Facilities Management Procurement (FMP) extends the posting or cancels it in preparation for the next Annual Prequalification Refresh. All document takers will be notified if the opportunity is closed earlier.

**Three rules this establishes:**

1. **One submission per discipline** → KOR = Structural → one submission.
2. **References must be Structural-specific.**
3. **Allocate KOR's structural fee** on multi-discipline projects (that's what's evaluated and what sets the fee band).

**Timing reality:** open now, rolling evaluation, close 30 Sept 2026 **but movable earlier** for the next refresh → **submit early; do not rely on the close date holding.**

## 7. Execution plan

### Phase 0 — Register + pull requirements (today, ~15 min)
- Go to https://fraserhealth.bonfirehub.ca/opportunities/101915
- Create / log into a **Euna-Bonfire vendor account** (use a durable KOR/BD shared inbox, not a personal one).
- **Register as a Document Taker** on 101915 (unlocks documents + puts KOR on the early-close/addendum notify list).
- **Download the full RFPQ package** (RFPQ doc + all appendices/forms + the "Requested Information" upload list). *This package is authoritative — reconcile Phase 2 against it.*
- Bonfire help: https://fraserhealth.bonfirehub.ca/portal/support

### Phase 1 — Decide scope & references (Ian + a principal, ~1 hr)
- Discipline: Structural — one submission.
- Choose cells to claim: **Non-Acute across every band with a real reference; Acute only where a genuine post-disaster / IE=1.5 reference exists.** Don't over-claim — unsupported cells get rated down.
- Pick strongest Structural references; map each to care-type, KOR's allocated structural fee → fee band, role (SEoR), value, client, completion, reference contact.

### Phase 2 — Assemble (expected LMFM components — confirm vs the download)
- Completed RFPQ response forms / appendices (firm profile, signed submission, addendum acknowledgement, declarations).
- **EGBC standing** — proof KOR is EGBC-licensed / Accredited Employer + list of registered structural P.Eng. staff.
- **Key-personnel resumes** — principals + structural P.Eng leads; foreground seismic / high-importance / post-disaster + BCBC-2024 fluency.
- **Structural project references** — discipline-specific (expect 3–5); each with KOR's allocated structural fee, contacts, care-type + fee band.
- **Insurance** — Professional Liability (E&O) + Commercial General Liability (COI or confirmation of limits).
- **WorkSafeBC** clearance + OHS/safety statement.
- **Business licence** / corporate registration.
- **Conflict-of-interest / declarations.**
- **Rated questionnaire responses** if the package includes a scored questionnaire.

### Phase 3 — Submit early (target ~2 weeks, well before 30 Sept)
- Upload each file to its correct Bonfire slot (one Structural submission); empty mandatory slots block submission.
- Check Bonfire file format / size limits.
- Submit; capture the confirmation (screenshot + email).

### Phase 4 — After
- Watch Bonfire + the registered email for clarification requests; respond fast (rolling evaluation rewards responsiveness).
- On qualification, KOR appears on the next refreshed list at the cells awarded → invited to LMFM/VCH tenders + proposal calls.
